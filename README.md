# 🏮 Little Kitchen - Taiwanese Bento Landing Page

> Authentic Taiwanese cuisine in Morley, Perth • ⭐⭐⭐⭐⭐ 5 Stars

## 🍜 Overview

This is the official landing page for **Little Kitchen** (小廚房), a Taiwanese bento restaurant located in Morley, Western Australia. The site showcases our authentic Taiwanese cuisine, menu offerings, location, and ordering information.

**Restaurant Details:**
- 📍 253 Walter Rd W, Morley WA 6062
- ⭐ 5-Star Rating on Hungry Panda & Google Maps
- ⏰ Open Tue-Sun, 11am-6pm (Closed Monday)
- 💰 $10-20 per dish

## 🚀 Quick Start

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## 🛠 Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** React Icons
- **Deployment:** Static export (Vercel/Netlify ready)
